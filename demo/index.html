⬢ ARCHX · VAULT (WEBGL)

Vault mode for premium images

Rendered by a WebGL shader that un-scrambles tiles on the GPU. The drawing buffer is not preserved, so even a prototype-bypass toDataURL returns pure black. Static Vault images now draw on demand (load/resize/lens/risk changes) instead of looping at 60 fps forever.

⚠ The honest limit (every vendor should tell you this)

If pixels reach a screen, a determined person can photograph the screen — no JavaScript can stop that; only DRM video pipelines (Widevine + HDCP) black out screenshots, and they don't exist for still images on the web. What Archx does guarantee: your original file is never sent, one-click & bulk theft stop working, automated scrapers get nothing, and anything that does leak is capped at display resolution and carries your watermark + a per-session forensic trace. That is the difference between “right-click, done” and “hours of reverse-engineering for a watermarked thumbnail”.

⌨️ Integration

Three ways in — pick per page. Server mode (recommended for anything valuable) takes ~6 lines in Node; client-only mode works on any static host today.

// ——— 1 · JS API (strongest: signed, scrambled, expiring delivery) ———
import Archx from '@archnemix/image-protection';

Archx.config({ tokenEndpoint: '/archx/token/' });
Archx.load.image('#hero', { id: 'aurora-valley' }, {
  mode: 'fortress',                    // 'lite' | 'shield' | 'vault' | 'fortress'
  qualityProfile: 'original',          // lossless legitimate view at display size
  lens: true,                          // one screenshot != one sharp full image
  temporalShield: { strength: 0.16 },  // one captured frame != the clean still
  captureShield: true,                 // drifting session/time trace (on in Fortress)
  cachePayload: true,                  // loaded once: scrolling/resizing never remints
  renderLoop: 'auto',                  // static images draw on demand, not 60fps forever
  watermark: '© My Studio · {session}',
  onExtract: 'black',                  // what canvas-grabbers receive
  onAttempt: (kind) => logToAnalytics(kind),
});
// Or start from an inspectable preset and override any single parameter:
// Archx.load.image(el, src, { ...Archx.preset('commerce'), temporalShield: false });

// ——— 2 · Client-only (any existing image URL or File/Blob) ———
Archx.load.image('#photo', 'https://cdn.example.com/photo.jpg', { mode: 'shield' });
Archx.load.image('#preview', fileFromInput, { mode: 'lite' });

// ——— 3 · Declarative ———
// <archx-image image-id="aurora-valley" mode="shield" watermark="© Studio"></archx-image>

// ——— Galleries (lazy, capped concurrency, cached/no-reload) ———
Archx.load.gallery('#grid', ids.map(id => ({ id })), { mode: 'lite' });

// ——— Server (Node, Express-compatible) ———
import { createArchxMiddleware } from '@archnemix/image-protection/server';
app.use(createArchxMiddleware({
  secret: process.env.ARCHX_SECRET,
  imagesDir: './masters',            // keep OUTSIDE your static/public folder
  ttlSec: 120, grid: 8,
  steganography: { perToken: true, strength: 6 },
  onStegoIssue: ({ id, viewerId, fingerprint }) => db.saveFingerprint({ id, viewerId, fingerprint }),
  authorize: async (req, id) => ({ viewerId: req.user.id, maxWidth: 1600, quality: 'lossless' }),
}));
