0 — Normal image (unprotected)

LEAST SECURE

Plain HTML <img>. Try right-click → Save image, drag it, or inspect the Network tab. This is the baseline problem.

View code
<img src="./luxury-watch.jpg" alt="Luxury watch">

1 — Lite mode

LIGHT

Fast protected viewer for galleries and listings. No normal image element is exposed; extraction returns a low-resolution decoy in this example.

View code
Archx.load.image('#liteImg', './luxury-watch.jpg', {
  mode: 'lite',
  qualityProfile: 'balanced',
  watermark: '© Archnemix · Lite',
  onExtract: 'lowres'
});

2 — Shield mode

DEFAULT

The recommended general-purpose mode: protected canvas, guards, watermark, per-session forensic pattern, and poisoned canvas read-back.

View code
Archx.load.image('#shieldImg', './luxury-watch.jpg', {
  mode: 'shield',
  qualityProfile: 'original',
  forensic: true,
  watermark: {
    text: '© Archnemix · {session}',
    tile: true,
    corner: true,
    opacity: 0.14
  },
  onExtract: 'scrambled'
});

3 — Vault mode

STRONG

WebGL rendering with a non-preserved drawing buffer, so ordinary canvas read-back returns black instead of the displayed pixels.

View code
Archx.load.image('#vaultImg', './luxury-watch.jpg', {
  mode: 'vault',
  qualityProfile: 'original',
  forensic: true,
  watermark: '© Archnemix · Vault · {session}',
  onExtract: 'black',
  renderLoop: 'static'
});

4 — Fortress mode

MAXIMUM PRESET

Vault plus strict memory, capture trace, temporal single-frame degradation, strike policy, and a pointer Lens. Move your mouse/finger over it: only the Lens area is sharp.

View code
Archx.load.image('#fortressImg', './luxury-watch.jpg', {
  mode: 'fortress',
  qualityProfile: 'original',
  lens: { radius: 0.32, idlePixelate: 18 },
  cameraShield: { pattern: 'checker', chroma: true, strength: 0.18, block: 2 },
  captureShield: true,
  watermark: '© Archnemix · Fortress · {session}',
  onExtract: 'black'
});

What changes as security rises?

GUIDE

Lite is cheapest. Shield adds stronger canvas/forensic behavior. Vault moves rendering to WebGL. Fortress assumes someone may screenshot or photograph the screen and makes one full sharp frame harder to obtain. Custom lets you choose only the layers you want.

Production warning 
For a real website, do NOT leave luxury-watch.jpg publicly downloadable
beside the page. Keep masters outside the web root and use either:

1) Archx token server  → browser asks for { id: 'luxury-watch' }
2) Pre-scrambled files  → browser loads luxury-watch.archx + key

Change the direct flags below and press Apply custom flags. The generated call uses mode: 'custom' plus a direct renderer flag; on Archx 1.3+ you may also omit mode entirely and pass only renderer and the individual flags. Patterned cameraShield options require Archx 1.4+; temporal interlace requires a current build that exposes Archx.normalizeTemporalInterlace.

These alternate complementary frames. A single capture keeps noise, but video averaging or a long exposure can defeat them; this is degradation, not camera-proofing.
Temporal interlace — 60 Hz-first subset frames
A single screenshot receives one incomplete phase, but screenshots from multiple phases, screen recording, and some camera exposures can recombine the image. Interlace always costs continuous presentation and is disabled for reduced-motion users by default.
